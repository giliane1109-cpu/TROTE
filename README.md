# TOTRE - Sistema de Gestão para Tornearia

Sistema integrado de gestão empresarial focado no controlo de clientes, vendas, ordens de serviço e módulo financeiro (contas a pagar, a receber e importação de notas fiscais).

## 🚀 Sobre o Projeto
Desenvolvido em formato de arquivo único para máxima portabilidade, utilizando HTML, Tailwind CSS, JavaScript puro e integração com a base de dados em nuvem Supabase. O projeto conta também com suporte a PWA (Progressive Web App) para instalação direta como aplicativo.

## 🛠️ Tecnologias Utilizadas
* **Frontend:** HTML5, Tailwind CSS (via CDN), FontAwesome.
* **Lógica:** JavaScript (ES6+).
* **Banco de Dados / Backend:** Supabase e LocalStorage para persistência local.
* **Bibliotecas Auxiliares:** PDF.js (para leitura de notas em PDF), Chart.js (para gráficos).

## 📱 Funcionalidades Principais
1. **Gestão de Cadastros:** Registo de clientes e fornecedores com painel de resumo lateral dinâmico.
2. **Módulo de Vendas:** Registo de pedidos, faturamento e reabertura.
3. **Módulo Financeiro:** Controlo de títulos, lançamentos e importação automática de notas fiscais (PDF/XML) em 3 passos.
4. **PWA Ativado:** Pronto para ser instalado no telemóvel ou computador.
